# Customer-Insights-and-Data-Analytics-Early-Remote-Internship
This repository documents my 4-week Customer Insights and Data Analytics Early Remote Internship under **"Saint Louis University"** in New York,USA through **"Excelerate"** website, focused on analyzing customer support operations using Freshdesk ticket data to generate insights, dashboards, forecasts, and AI-driven workflow optimization strategies.

# 📇 Internship Overview
    • Dataset (Raw): Freshdesk Customer Support Tickets Dataset (30×11)
    • Dataset (Cleaned): Cleaned_Ticket_Dataset
    • Tools: Python, Excel, Power BI, Freshdesk, Canva

# 🎯Techniques & Focus Areas (Skills Gained):
    • Data cleaning & preprocessing
    • Ticket mapping & categorization
    • Manual tagging & sentiment analysis
    • Recurring issue identification
    • KPI design & operational metrics
    • Dashboard design & visualization
    • Trend analysis & forecasting
    • Workflow automation design
    • Service performance optimization

# 🗓️ Weekly Tasks Breakdown

    • Week 1:Ticket mapping, data completion, recurring issue analysis, and support workflow simulation design.
    • Week 2:Data cleaning, standardization, manual tagging, sentiment classification, and early pattern discovery.
    • Week 3:Power BI dashboard development, KPI analysis, operational bottleneck detection, and ticket volume forecasting.
    • Week 4:Strategic insights development, workflow automation design (Freshdesk scenarios), service optimization recommendations, executive reporting, and final presentation.

# 🎯 Outcome
This internship delivered an end-to-end analytics workflow, transforming raw support ticket data into actionable business intelligence. The project strengthened skills in data analytics, visualization, forecasting, dashboarding, and AI-driven workflow design, while bridging operational efficiency with customer experience optimization.
